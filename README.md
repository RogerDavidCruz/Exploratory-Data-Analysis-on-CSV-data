# Guided Lab 386.3.5 – Exploratory Data Analysis (EDA) on CSV Data

## Overview
This lab introduces the fundamentals of Exploratory Data Analysis (EDA) using Python and the Pandas library. The exercises focus on loading, inspecting, and manipulating CSV data while exploring common techniques used in real-world data analysis.

## Objectives
- Load CSV data into a Pandas DataFrame
- Explore datasets using `head()`, `tail()`, `info()`, `shape`, and `columns`
- Read CSV files with different options
- Skip rows and select specific columns using `read_csv()`
- Perform basic data exploration and identify missing values

## Technologies Used
- Python 3
- Pandas
- Google Colab / Jupyter Notebook

## Topics Covered
- Reading CSV files with `pd.read_csv()`
- Viewing and inspecting data
- Understanding DataFrame structure
- Selecting columns with `usecols`
- Skipping rows with `skiprows`
- Basic Exploratory Data Analysis (EDA)

## Dataset
- `employee.csv` (sample employee dataset)

## Learning Outcome
By completing this lab, I gained hands-on experience with importing CSV files, exploring datasets, handling basic data loading options, and performing foundational EDA using Pandas.
